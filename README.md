# 异闻旅者（Lostbelt Traveler）

本项目是一个泰拉瑞亚模组。
本模组旨在将型月（Type-Moon）系列作品（以《命运/冠位指定》为主）与泰拉瑞亚进行结合后创作的内容模组，也作为型月二创作品，同时与旅人归途（Homeward Journey）拥有进一步的深度联动。
由于模组目前内容不多，因此极其推荐与旅人归途一起携带游玩！

## 主要内容

### 新职业：代行者
代行者来自异界的暴力机关，因某些原因来到了泰拉瑞亚大陆。
其表现形式上可以视作“散人”转正，因此其武器池几乎覆盖了泰拉瑞亚内所有的武器类型。
代行者的所有武器在命中满足一定次数后，即可触发处决攻击。
目前代行者一共拥有六类武器：

- **投掷品（Thrown）**：专门指代一系列以投掷作为动作，将武器脱手的武器系列，该系列的处决攻击都会获得另类的攻击效果。
- **不脱手冷兵器（Cold Steel）**：专门指代一系列不会离手的冷兵器，如刀剑和弓，该系列处决攻击以增强武器的素质为主。
- **热武器（Firearm）**：专门指代枪、炮等一系列动能类热武器，该系列处决攻击以增强武器的素质为主。
- **魔术载体（Caster）**：专门指代以法杖、法书等作为载体点魔术武器，该系列处决攻击会切换为一种完全与魔法载体无关的攻击模式。
- **支援道具（Assistance）**：由召唤师派生，指代鞭子等一系列攻击模组简单的武器，该系列处决攻击将就增强代行者的各类素质。
- **特殊（Misc）**：上述五种都无法准确归类的武器。

### 异闻侵染
模组的核心机制之一，但可以为适配而选择性开关。
异闻侵染机制会为模组添加如下内容：
- 部分原版 Boss 的专属特殊音乐。
- 敌人的攻击部分视觉效果乃至贴图层面的修改。
- （旅人归途联动专属）旅人内容物品的视效重置。
- 部分原版物品获得全新的属性。

### 格挡盾
在游戏早期流程即可解锁的强化能力。原版与旅人归途的部分盾牌现在可用于增强格挡盾能力。
格挡盾机制简介：
1. 格挡盾每次成功命中时都会直接给予玩家 60 帧的无敌时间，并给对应的敌人增加 20% 的格挡进程，触发这几个效果之后会进入固定 3 秒的冷却时间（期间不影响继续挥舞格挡盾）。
2. 格挡进程满上时做掉敌对单位的 AI 进程并标记为被格挡状态 5 秒时间，同时清空格挡进程，并触发对应的格挡盾能力。被格挡的敌人会被冻结 AI。
3. 只有允许被格挡的敌人才会被冻结 AI。
